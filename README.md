# Выполнение заданий 
## Описание
Репозиторий создан для выполнения тестовых заданий на языке программирования `Python`

## Необходимые установки 
Для запуска всех скриптов необходимо выполнить установку библиотеки `requests` 

## Задача 1. Получение прогноза погоды
Скрипт возвращает данные о погоде по городу Москва в формате:
1. ч/б оформление
2. скорость ветра в м/с
3. текст на русском языке
4. температура указана в цельсиях

Запуск скрипта происходит при непосредственном вызове скрипта
```python
python weather.py
```

___
## Задача 2. Конвертер валют
Скрипт принимает первым аргументом - числовое значение, переводимой валюты, 
вторым аргументом - буквенное сокращение валюты  

**Пример** запуска скрипта для получения значения валюты в **рублях**
```python
python converter.py 100 USD
```
___
## Задача 3. Астронавты
Скрипт возвращает количество людей находящихся в космосе, а также корабль на котором они находятся астронавты

Запуск скрипта происходит при непосредственном вызове скрипта
```python
python astronauts.py
```
